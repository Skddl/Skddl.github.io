# Adrian Jhelo Dimapilis Negre — Portfolio

Personal portfolio site built with HTML, CSS, and JavaScript. The featured CSE Exam Reviewer opens the existing Netlify project.

## GitHub Pages

The Pages workflow deploys the contents of `site/` to the personal site at `https://skddl.github.io/`. Push updates to `main` to publish changes.

## Netlify

The root `netlify.toml` is also configured to publish `site/` if you choose to connect this repository to Netlify.

No build command or package install is required.
